## MyMovieRatings

MyMovieRatings consists in a Web Application for movie lovers. The application consists in a platform for movie search and management. Browse through all titles, add movies to your watchlist, save them for later, rate and manage the films you watched!

## Project Objetive

The project was developed in class. The main objetive was to create a mobile app or web application using the skills and principles learned in class. Platform is all based in JavaScript, using React and React Native.
