# 🎬MyMovieRatings

MyMovieRatings consists in a Web Application for movie lovers. The application consists in a platform for movie search and management. Browse through all titles, add movies to your watchlist, save them for later, rate and manage the films you watched!


![tela_inicial_mymovieratings](https://github.com/user-attachments/assets/23af26c1-1e18-4e6f-b17b-f27dc78633c0)

---

## 🛠️Main Features


- 🔍 Search for movies
- ⭐ Rate Your movies
- 📂 Add movies to your Watchlist
- 📄 Visualize movie details
- 💾 Keep your data saved

## 💻Technologies Used

This project was developed using:
- JavaScript
- React / React Native (Expo)
- Node.js (included in Expo dependencies)
- The Open Movie Database (OMDb API)
- HTML / CSS

---

## ▶️How to Install and Execute
Installation via terminal on command line (bash):
```bash
# installing Expo CLI
npm install -g expo-cli

# cloning the repository
git clone https://github.com/renanjfa/MyMovieRatings.git

# acessing the directory
cd MyMovieRatings

# installing dependencies
npm install

# execute the project on web environment
npx run web

```
